# Toán 6 • Ôn luyện giữa kì 1 (2026–2027)
Web tĩnh một file (index.html), không cần cài đặt hay build.

## Cách đưa lên mạng (GitHub + Vercel)
1. Vào github.com → New repository → đặt tên `toan6-on-giua-ki-1` → Create.
2. Bấm "uploading an existing file" → kéo thả 3 file: `index.html`, `vercel.json`, `.gitignore` → Commit changes.
3. Vào vercel.com → Add New → Project → chọn repo vừa tạo → Deploy (giữ mặc định, không chọn framework).
4. Sau vài chục giây có địa chỉ dạng `toan6-on-giua-ki-1.vercel.app` → gửi cho học sinh (hoặc tạo mã QR).

## Cập nhật sau này
Sửa/ghi đè `index.html` trên GitHub → Vercel tự đăng lại.

## Ghi chú
- Học sinh chơi ngay, không cần tài khoản. Biệt danh và tiến trình lưu trong trình duyệt của từng em.
- Bản nháp: cô duyệt trước khi phát cho học sinh.
